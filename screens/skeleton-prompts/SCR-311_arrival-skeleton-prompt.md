# SCR-311 목적지 도착 알트 — Skeleton Prompt

## Context

- 화면 크기: Mobile app `393 x 852`.
- 진입: `SCR-309` 자율주행 종료/도착.
- 이탈: 일반 출동은 완료 후 종료, 응급 출동은 일지 생성으로 FLOW-006 진입, 목적지 추가는 주소 선택 또는 운행 생성으로 재진입.
- 화면 유형: 자율주행 화면 위에 뜨는 목적지 도착/운행 종료 알트. 환자일지 상세 작성 화면은 이번 skeleton 범위에서 제외한다.
- 수동주행은 주행자가 수동주행 화면에서 직접 완료 처리하므로 이 알트를 띄우지 않는다.

## Flow Coverage

- 자율주행 도착/종료 흐름: `SCR-309 자율주행 화면 -> @floating-arrival-alert`.
- 일반 출동 완료: `@floating-arrival-alert 완료 -> Exit`.
- 응급 출동 후속: `@floating-arrival-alert 일지 생성 -> 일지 생성 진입`까지만 표시하고, 환자일지 상세 화면은 만들지 않는다.
- 목적지 추가: `@floating-arrival-alert 목적지 추가 -> 주소 선택/주행 생성 재진입` 가능성을 flow rail에 표시한다.
- 수동주행 종료 흐름은 `SCR-310` 내부에서 완료되며, `SCR-311` 알트로 합류시키지 않는다.

## Skeleton Objective

자율주행 종료 후 사용자가 도착/종료 상태를 인지하고, 하나의 알트 안에서 완료, 일지 생성, 목적지 추가 후속 액션을 모두 확인할 수 있는지 검증한다. 이 알트는 자율주행 화면 위에 플로팅되어야 하며, 환자일지 상세 화면으로 확장하지 않는다.

## Structural Layout

- 최상위 섹션: `SCR-311.arrival-skeleton-set`.
- 섹션 안에 `arrival-alert-on-autonomous-driving` 단일 알트 상태 프레임을 둔다.
- 배경은 `SCR-309` 자율주행 진행 화면의 지도/ETA/차량 상태/하단 제어가 보이는 상태로 구성한다.
- `@floating-arrival-alert`: 자율주행 화면 위에 뜨는 도착/종료 알트. 도착 완료 안내, 목적지 주소, 운행 요약, 세 가지 CTA를 모두 포함한다.
- `@actions`: 같은 알트 안에 `완료`, `일지 생성`, `목적지 추가` 버튼을 모두 표시한다.
- `@flow-rail`: 자율주행 화면 위 알트에서 완료/일지 생성/목적지 추가로 분기되는 흐름. 수동주행은 별도 종료 흐름으로 표기하고 알트 합류선을 연결하지 않는다.

## Controls And Feedback

- 알트 안에 `완료`, `일지 생성`, `목적지 추가` CTA를 한 번에 모두 표시한다.
- `완료`: 일반 출동 완료 또는 운행 종료 처리.
- `일지 생성`: 구급활동 일지 진입까지만 표시한다. 환자일지 상세 내용은 그리지 않는다.
- `목적지 추가`: 목적지 선택 또는 주행 생성으로 재진입하는 흐름만 표시한다.
- 도착/종료 안내는 화면 본문 카드가 아니라 자율주행 화면 위에 뜨는 알트로 표현한다.

## State Variants

- `arrival-alert-on-autonomous-driving`: 자율주행 화면 위에 도착/종료 알트가 뜬 상태. `완료`, `일지 생성`, `목적지 추가`가 하나의 알트 안에 모두 표시된다.

## Floating Layers

- 도착/종료 알트는 `@floating-arrival-alert`로 표현한다.
- 알트는 `SCR-309` 자율주행 화면 위에 떠 있는 관계가 보이게 하며, 일반 본문 카드처럼 배치하지 않는다.
- 수동주행 화면 위에는 이 알트를 만들지 않는다.
- 환자일지 상세 입력 UI는 만들지 않는다.

## Skeleton UX Checks

- SCR-311 알트가 자율주행 화면 위에 플로팅된 관계로 보인다.
- `완료`, `일지 생성`, `목적지 추가`가 하나의 알트 화면에서 모두 보인다.
- 수동주행 종료가 SCR-311 알트로 합류하지 않는다는 점이 flow rail에서 확인된다.
- 응급 출동은 일지 생성 진입까지만 표시하고 환자일지 상세는 제외한다.
- 도착/종료 안내가 본문 요소처럼 보이지 않고 플로팅 알트로 보인다.
- 사용자 UI에는 화면 ID, 내부 변수명, TBD, 구현 설명을 표시하지 않는다.
