# State Policy

## 1. Purpose

V1.1에서 추가/변경되는 자율주행 관련 상태값, 상태 전이, 표시 우선순위, 제어 가능 조건을 정의한다.

이 문서는 PRD와 IA 이후 Feature Spec, Flow, Screen Spec, API/Event Contract를 작성할 때 기준으로 사용한다.

## 2. Scope

| 구분 | 포함 내용 |
| --- | --- |
| 주행 모드 | 자율주행중, 수동주행중, 원격제어중, 원격재배치중 등 |
| 요청 상태 | 원격주행 요청, 승인대기, 승인, 거절, 타임아웃 |
| 차량 상태 | 대기, 주행중, 비정상 |
| 제어 상태 | 제어 가능, 안전정차대기, 컨트롤 패널 락 |
| 경로 상태 | 일반 경로, 응급 경로, 경로 이탈, 경로 갱신 |
| 알림 상태 | 긴급 경로 진입 알림, 수동 전환 알림 |

## 6. Vehicle Availability State

차량상태 표시값은 `대기 / 주행중 / 비정상`으로 확정한다. 단, 각 상태의 시스템 판정 기준은 협의 필요하다.

| State ID | 상태명 | 정의 | 진입 조건 | EMS 키오스크 표시/동작 | 상태 |
| --- | --- | --- | --- | --- | --- |
| STATE-441 | 대기 | 차량이 운행 요청을 받을 수 있는 상태 | 판정 기준 협의 필요 | 차량상태 대기로 표시 | 협의 필요 |
| STATE-442 | 주행중 | 차량이 현재 운행 중인 상태 | 판정 기준 협의 필요 | 차량상태 주행중으로 표시 | 협의 필요 |
| STATE-443 | 비정상 | 차량이 운행 또는 상태 조회에 비정상 조건을 가진 상태 | 판정 기준 협의 필요 | 차량상태 비정상으로 표시, 운행 제어 제한 가능 | 협의 필요 |
| STATE-444 | 차량상태 미응답 | 차량 시동 꺼짐 등으로 10초 내 응답이 없는 상태 | 차량상태 조회 후 10초 초과 | SCR-305에서 타임아웃 안내 표시 | Confirmed |

## 12. Display Priority

여러 상태가 동시에 발생할 수 있으므로 EMS 키오스크는 아래 우선순위로 사용자에게 표시한다. 최종 우선순위는 협의 필요하다.

| 우선순위 | 상태/알림 | 이유 | 상태 |
| --- | --- | --- | --- |
| 1 | 수동 전환 알림 | 운전자 조작으로 제어 주체가 즉시 바뀌는 안전 관련 상태 | Draft |
| 2 | 안전정차대기 / 컨트롤 패널 락 | 사용자의 제어 가능 여부에 직접 영향 | Draft |
| 3 | 원격주행 요청 알림 | 승인/거절 사용자 응답 필요 | Draft |
| 4 | 긴급 경로 진입 예정 | 주행 맥락 알림 | Draft |
| 5 | 경로 이탈 / 경로 갱신중 | 경로 표시 및 ADS 전달 상태 | Draft |
| 6 | 실시간 차량 상태 | 상시 정보 표시 | Confirmed |
