# Visual Direction — 구급 이송 조율 모바일 앱

## 서비스 맥락
- 사용자: 119 구급대원 (구급차 내 모바일 사용)
- 사용 환경: 이송 현장, 이동 중, 장갑 착용 가능, 긴박한 상황
- 핵심 과업: 구급일지 작성, 환자 평가, 병원 선택·이송 조율

## 비주얼 톤
**친근 · 활동적 · 컬러풀**

- 긴박한 현장에서도 부담스럽지 않은 따뜻한 톤
- 색상으로 카테고리와 상태를 직관적으로 구분
- 딱딱한 의료 도구가 아닌, 현장 동료 같은 느낌

## 브랜드 방향
- Primary: Blue/600 #1570EF — 주요 액션, 활성 상태
- 상태 색상 원칙: **풍부하게** — 카테고리별 컬러 구분
  - KTAS 레벨 5단계 각각 고유 색상
  - 승인 상태(승인/대기/거절/만료) 각각 고유 색상
  - 탭·섹션별 accent 색상 허용
  - 색상이 단순 장식이 아닌 **정보 전달 목적**일 때만 사용

## 밀도 & 레이아웃
- 밀도: **조밀** — 스크롤 최소화, 화면당 정보량 극대화
- 여백 원칙:
  - 섹션 간: space-4 (16px) — 일반 대비 축소
  - 필드 간: space-2 (8px) ~ space-3 (12px)
  - 카드 내부: space-3 (12px)
  - 화면 좌우: space-4 (16px) 유지
- 스크롤 전략: 긴 폼은 탭/아코디언으로 분할, 단일 스크롤 지양

## Elevation & Surface
- 스타일: **구조적** — 테두리 선명, 섹션 구분 명확
- 테두리가 주 구분 수단, 그림자는 부차적
- 카드: 1px border (Gray/200) + radius-lg (12px)
- 섹션: 배경색 교차 또는 테두리 + 섹션 헤더로 구분
- 모달/바텀시트만 Shadow/lg 사용
- 하단 고정 바: 상단 1px border + Shadow/xs

## Surface 계층 실효성
| 계층 쌍 | 토큰 A → B | ΔL | 판정 |
|---------|-----------|-----|------|
| 배경 ↔ 카드 | Gray/50 → White | 0.044 | 충분 |
| 배경 ↔ 섹션 구분 | Gray/50 → Gray/100 | 0.024 | 경고 — 테두리 병용으로 허용 |

> 조정: background를 Gray/50, surface-secondary를 Gray/100으로 한 단계 내림.
> 구조적 스타일에서 테두리가 1차 구분이므로 ΔL 0.024도 실용적으로 충분.

## 색상 분배 규칙
| 위치 | 허용 색상 | 역할 | 면적 기준 |
|------|----------|------|----------|
| 카드 좌측 상태 바 (4px) | 상태색 (success/warning/error/muted) | 승인 상태 즉시 인지 | 카드 높이 × 4px |
| KTAS 레벨 배지 | 레벨별 고유색 (design-system.md 참조) | 중증도 즉시 인지 | 배지 크기 |
| 섹션 헤더 바 | primary 또는 카테고리 accent | 섹션 앵커, 현재 위치 인지 | 헤더 높이 × 전폭 |
| 칩/태그 배경 | 카테고리별 subtle 배경 + 해당 색상 텍스트 | 분류 표시 | 칩 크기 |
| 아이콘 강조 | 상태색 또는 primary | 시각 앵커 | 아이콘 크기 |
| 탭 활성 인디케이터 | primary | 현재 탭 표시 | 탭 하단 2~3px |
| CTA 버튼 | primary (filled) | 핵심 액션 | 버튼 크기 |
| 인라인 배너 | 상태색 subtle 배경 | 알림·안내 | 전폭 × 배너 높이 |

**금지:**
- 장식 목적 배경 블록
- 카드 전체를 상태색으로 칠하기 (좌측 바만 허용)
- 무목적 accent 사용
- 동일 화면에 5색 이상 동시 사용 (KTAS 배지 예외)

## 아이콘 스타일
- **혼합 방식**: 비활성 = 라인(Outline), 활성/강조 = 솔리드(Filled)
- 탭 바: 비활성 라인 → 활성 솔리드 + primary 색상
- 상태 아이콘: 솔리드 (체크, X, 시계 등) + 해당 상태색
- 일반 보조 아이콘: 라인, Gray/600

## 창의적 디자인 방향
- 개성 수준: **높음** — 화면마다 고유한 레이아웃
- S01 (구급일지): 5탭 폼, 아코디언 + 인라인 확장, 최대 밀도
- S02 (pre-KTAS): 3스텝 위자드, 추천 카드 2장 + 수동 선택, 단계 진행감
- S03 (병원 선택): 서브 탭(추천/검색), 체크박스 카드 리스트, 하단 요약 바
- S04 (승인 상태): 실시간 상태 카드, 좌측 상태 바, 라디오 선택
- S05 (이송 완료): 성공 일러스트 + 요약 카드, 넓은 여백 (예외적 여유)
- M01 (이송 확인): 모달, 요약 정보 + 버튼 쌍
- **금지**: 모든 화면을 동일 카드 구조로 만드는 것

## 강조 방식
- **배경 + 컨테이너** 우선
- 강조 항목: 색상 배경 블록 또는 컨테이너로 감싸기
- 2차 강조: 컬러 텍스트 + 볼드
- 비활성/비강조: Gray 톤 + 일반 굵기
- 예시:
  - 승인 병원 카드: Blue/50 배경 + Blue/600 좌측 바
  - KTAS 레벨: 레벨색 배경 배지 + White 텍스트
  - 필수 입력 미완료: Error/50 배경 + Error 테두리

## 확정 디자인 결정
| 주제 | 결정 | 이유 |
|------|------|------|
| 비주얼 톤 | 친근·활동적 | 긴박한 현장에서 부담 줄이고 직관적 사용 유도 |
| 색상 철학 | 풍부하게 | KTAS 5단계 + 상태 4종 + 카테고리 구분 필요 |
| 밀도 | 조밀 | 180+ 필드, 현장 스크롤 최소화 |
| 컨테이너 | 구조적 (테두리 중심) | 조밀한 데이터에서 영역 구분 필수 |
| 강조 | 배경 + 컨테이너 | 색상 풍부 + 조밀 밀도에서 명확한 계층 |
| 아이콘 | 혼합 (라인/솔리드) | 활성 상태 시각적 위계 자연스럽게 형성 |
| 화면 개성 | 높음 | 6개 화면 각각 역할이 뚜렷, 최적화 레이아웃 |
| Surface 조정 | background→Gray/50, secondary→Gray/100 | 구조적 스타일 + 배경 대비 확보 |
