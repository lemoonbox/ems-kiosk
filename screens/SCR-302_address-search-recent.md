## 2. Screen Purpose

### Observed

- 검색 입력 영역에 `출동 주소를 검색하세요`가 표시된다.
- 즐겨찾기 1/2와 편집 아이콘이 표시된다.
- 최근 검색 주소가 최대 5개까지 목록으로 표시된다.

### V1.1

- 즐겨찾기는 항상 즐겨찾기 목적지 선택 기능이다.
- 주소 검색창 바로 아래에 즐겨찾기를 보여준다.
- 즐겨찾기 등록/수정은 별도 즐겨찾기 관리 화면에서 처리한다.
- 최근 검색은 최신순으로 정렬하고 1개월 보관한다. 1개월이 지나거나 5개를 초과하면 자동 삭제한다.
- 원격재배치 버튼으로 경로 검색에 진입한 경우에도 이 화면의 즐겨찾기 자체는 목적지 선택 수단으로만 동작한다.
- 원격재배치 버튼 진입 여부는 후속 주행 상태를 `원격재배치중`으로 표기하기 위한 플래그로 관리한다.

### Questions

- 없음. 최근 검색 정책과 즐겨찾기 관리 범위는 사용자 확인 완료.
