# SCR-302 주소검색 — Skeleton Prompt

## Context

- 화면 크기: Mobile app `393 x 852`.
- 진입: `SCR-301`의 목적지 검색 선택.
- 이탈: 검색어 입력 시 `SCR-303`, 최근 검색/즐겨찾기 선택 시 `SCR-304`.
- 화면 유형: 주소 선택의 초기 상태. 최근 검색과 즐겨찾기를 통해 검색 없이 목적지를 선택할 수 있다.

## Flow Coverage

- 기본 검색 흐름: `SCR-301 -> SCR-302 -> SCR-303 -> SCR-304`.
- 빠른 선택 흐름: `SCR-301 -> SCR-302 -> SCR-304`.
- 원격운행의 주소 지정은 센터 시스템에서 처리된다. 센터가 주소를 검색/지정해 원격운행이 시작되면 앱은 주소 검색 화면이 아니라 자율주행 진행 화면으로 이동한다.
- skeleton에는 `주소검색` 단계가 전체 주행 생성 플로우의 두 번째 단계임을 나타내는 flow rail을 포함한다.

## Skeleton Objective

검색어 입력 전 상태에서 검색창 바로 아래 즐겨찾기, 최근 검색, 직접 검색이 모두 목적지 선택 경로로 읽히는지 검증한다. 최근 검색은 최대 5개, 최신순, 1개월 보관 기준으로 표시한다. 원격운행 전용 주소 검색 상태는 만들지 않는다.

## Structural Layout

- 최상위 섹션: `SCR-302.address-search-skeleton-set`.
- 섹션 안에 `default`, `empty-recent` 프레임을 나란히 둔다.
- `@header`: 뒤로가기, 검색 입력 필드, 검색 실행 아이콘.
- `@content`: 검색창 바로 아래 즐겨찾기 영역, 최근 검색 주소 목록.
- `@flow-rail`: 홈에서 검색으로 진입하고 선택 후 목적지 확인으로 나가는 흐름을 표시한다.
- 고정 footer는 만들지 않는다.

## Controls And Feedback

- 검색 입력: `출동 주소를 검색하세요`.
- 즐겨찾기: 검색창 바로 아래 2개 shortcut과 편집 아이콘 위치. 편집은 별도 즐겨찾기 관리 화면으로 이어지는 흐름만 표시한다.
- 최근 검색: 최대 5개 list row. 최신순이며, 1개월 경과 또는 5개 초과 시 자동 삭제되는 정책은 문서에만 남기고 사용자 UI에는 설명하지 않는다. 선택 가능한 행임을 터치 영역과 구분선으로 표시한다.
- 원격운행 진입 상태는 이 화면에 만들지 않는다.

## State Variants

- `default`: 일반 목적지 검색 진입.
- `empty-recent`: 최근 검색이 없고 즐겨찾기만 있는 상태.

## Floating Layers

- 기본 팝업/알림 없음.
- 즐겨찾기 편집은 이번 skeleton 범위에서 플로팅 레이어로 만들지 않는다.

## Skeleton UX Checks

- 검색어 입력과 최근/즐겨찾기 선택의 이탈 경로가 다르게 보인다.
- 최근 검색 행이 충분히 선택 가능한 영역으로 보인다.
- 원격운행 주소 지정 상태가 이 화면에 섞이지 않는다.
- 여러 상태 프레임은 하나의 `SCR-302.address-search-skeleton-set` 안에 묶인다.
- 사용자 UI에는 화면 ID, 내부 변수명, TBD, 구현 설명을 표시하지 않는다.
