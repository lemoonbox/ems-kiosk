## How to Add a Flow Spec

1. [_FLOW_TEMPLATE.md](./_FLOW_TEMPLATE.md)를 복사한다.
2. 파일명을 `FLOW-XXX_flow-name.md` 형식으로 변경한다.
3. 사용자가 제공한 피그마 화면 순서와 노드를 기록한다.
4. 플로우 목적, 시작 조건, 종료 조건을 먼저 정리한다.
5. 화면 순서대로 `SCR-XXX`를 등록한다.
6. 각 화면에서 기능, 정책, 데이터, 질문을 추출한다.
7. 확정되지 않은 내용은 [../07_OPEN_QUESTIONS.md](../07_OPEN_QUESTIONS.md)에 등록한다.
