# Service Plan — EMS Kiosk

## 서비스 개요

EMS 키오스크 / APP 컨트롤은 국토부-15 AI 자율주행 앰뷸런스 과제의 모바일 앱 화면이다. 사용자는 목적지를 설정하고, 주행 방식을 선택하고, 경로와 차량 상태를 확인하며, 자율주행/수동주행/원격주행 관련 제어를 수행한다.

V1.1의 핵심은 기존 자율주행 생성 플로우를 유지하되 운행 차량 선택을 제거하고, 주행 중 상태 변화와 제어 제한을 더 명확히 다루는 것이다.

## 사용자

| 역할 | 사용 맥락 | 주요 행동 |
|---|---|---|
| EMS 키오스크 사용자 | 앱에서 목적지, 주행 방식, 상태를 확인하고 제어한다. | 목적지 검색, 주행 옵션 선택, 경로 확인, 주행 제어, 병원 이송 요청 |
| 앰뷸런스 운전자 | 실제 차량을 운행하며 수동 전환을 발생시킬 수 있다. | 운전대/페달 조작, 수동 운행, 정차 |
| 센터 관제자 | 센터시스템에서 원격주행 요청/승인 및 경로 갱신을 처리한다. | 원격 요청 송신/승인, 경로 재생성, 상태 이벤트 송신 |

## 범위

### 필수 범위

- 목적지 검색, 최근 검색, 즐겨찾기 기반 목적지 선택
- 목적지 확인과 경로 생성 요청
- 주행 옵션 설정: 수동주행/자율주행, 일상 업무/응급 출동, 원격 주행 신청
- 운행 차량 선택 제거: 차량은 1대뿐이며 사용자가 차량을 선택하지 않는다.
- 앰뷸런스 차량상태 조회와 10초 미응답 타임아웃
- 응급/일반 경로 동시 표시와 지도 위 경로 표시 전환
- 자율주행 중 실시간 차량 상태: 속도, 위치, heading, 주행 모드
- 원격주행 요청의 승인대기/승인/거절/타임아웃 상태
- 긴급 경로 진입 알림, 수동 전환 알림, 경로 이탈/갱신 상태
- 안전 정차 전 컨트롤 패널 잠금
- 최적이송병원 추천과 병원 이송 요청/대기/재요청

### 제외 범위

- 차량 2대 이상 선택 프로세스
- 카카오 API 내부 경로 생성 알고리즘
- ADS 내부 안전 정차 판단 로직
- 병원 별도 기기의 승인/거절 UI
- 센터/ADS 내부 알고리즘 상세 구현

## 도메인 데이터

| 데이터 | 사용 화면/기능 | 출처 | 비고 |
|---|---|---|---|
| 출동 주소 | SCR-301~SCR-304 | 주소 검색/즐겨찾기/스케줄 | 경로 생성 입력 |
| 스케줄 목적지 | SCR-301, SCR-304/SCR-305 | 스케줄 | 스케줄은 항상 목적지를 가진다. |
| 차량상태 | SCR-305, SCR-309 | 차량 시스템/센터 | 대기/주행중/비정상, 판정 기준은 논의 필요 |
| 일반 경로 / 응급 경로 | SCR-307, SCR-309 | 센터시스템/지도 API | 지도 위 표시 전환 대상 |
| 원격주행 요청 상태 | SCR-305, SCR-309 | EMS/센터 | 승인대기/승인/거절/타임아웃 |
| 실시간 차량 상태 | SCR-309 | 센터 또는 ADS | 속도, 위치, heading, 주행 모드 |
| 안전 정차 상태 | SCR-309 | ADS 또는 센터 | 제어 잠금과 후속 처리 기준 |
| 병원 추천 결과 | SCR-312 | 외부 AI API | 병원 이송 요청 입력 |

## 목표와 지표

| ID | 목표 | 검수 기준 |
|---|---|---|
| GOAL-001 | 목적지 설정 후 주행 방식을 선택해 주행을 시작할 수 있다. | 목적지 검색부터 주행 시작까지 플로우 연결 |
| GOAL-002 | 응급 자율주행에서 일반/응급 경로를 모두 확인할 수 있다. | 두 경로 표시와 표시 전환 동작 |
| GOAL-003 | 주행 중 차량 상태와 주행 모드를 즉시 파악할 수 있다. | 속도, 위치, heading, 모드 표시 |
| GOAL-004 | 원격주행 요청을 승인대기/승인/거절/타임아웃으로 처리한다. | 상태별 UI와 이벤트 처리 |
| GOAL-005 | 안전 정차 전 위험한 제어를 제한한다. | 컨트롤 잠금과 상태 안내 표시 |
