# SCR-309 자율주행 진행 — Skeleton Prompt

## Context

- 화면 크기: Mobile app `393 x 852`.
- 진입: `SCR-307`에서 주행시작, `SCR-305` 원격 주행 승인, 또는 원격재배치 플래그가 있는 자율주행 시작.
- 이탈: 목적지 도착 또는 안전 정차 후 종료 시 자율주행 화면 위에 `SCR-311` 도착/종료 알트가 뜨며, 수동 전환 후 자율주행 재요청 시 `SCR-307`.
- 화면 유형: 주행 중 지도 기반 상태 화면. 지도, ETA, 차량 상태, 주행 제어, 플로팅 알림이 동시에 존재한다.

## Flow Coverage

- 자율주행 정상 흐름: `SCR-307 -> SCR-309 -> SCR-311 도착/종료 알트`.
- 일시정지 흐름: `일시 중지 선택 -> 정차모드 전환/화면 프리즈 -> 안전정차대기 -> 정차 완료 -> 프리즈 해제 + 운행 재시작 -> 기존 경로 재시작 확인 알트 -> 확인 시 자율주행 재개`.
- 주행 종료 흐름: `주행 종료 선택 -> 종료 확인 모달 -> 확인 -> 안전정차대기 -> 안전정차 완료 -> SCR-311 도착/종료 알트`.
- 수동 전환 흐름: `운전대/페달 조작 -> 수동주행중 플로팅 알림 -> 정차 시 주행 종료 또는 자율주행 재요청`.
- 센터 원격 요청 흐름: `센터 요청 수신 -> 플로팅 승인/거절 알림 -> 승인 시 원격제어중, 거절 시 기존 주행 유지`.
- 경로 갱신 흐름: `경로 이탈 -> 경로 갱신중 -> 갱신 경로 반영`.
- flow rail에는 정상 주행, 제어 잠금, 수동 전환, 센터 요청, 경로 갱신, 종료 흐름을 같은 화면의 상태 변화로 표시한다.

## Skeleton Objective

자율주행 진행 중 여러 상태가 같은 화면에서 바뀐다는 점을 검증한다. 상태값이 여러 개라면 빠짐없이 그리고, 같은 화면의 여러 상태라는 것을 알 수 있도록 하나의 screen-set 섹션 안에 묶는다. 팝업/알림/토스트는 본문 요소가 아니라 화면 위에 뜨는 플로팅 레이어로 표현한다.

## Structural Layout

- 최상위 섹션: `SCR-309.autonomous-driving-progress-skeleton-set`.
- 섹션 안에 상태별 모바일 프레임을 둔다: `driving-default`, `safe-stop-waiting`, `paused-ready-to-restart`, `restart-confirm-alert`, `end-confirm-modal`, `manual-override`, `manual-override-not-stopped`, `remote-request`, `remote-control`, `remote-relocation`, `emergency-route-alert`, `route-deviation`, `route-updating`, `route-updated`.
- 모든 상태 프레임은 같은 기본 구조를 공유한다.
- `@header`: 목적지 주소와 현재 주행 모드 상태칩.
- `@content`: 지도 영역. 탑 메뉴 하단부터 하단 플로팅 버튼 바로 상단까지 확장한다. 현재 위치, 주행 경로, 목적지 마커, 갱신 경로를 단순 도형으로 표시하고, 차량 방향은 지도 안 원형 위치 마커와 정렬된 삼각형 화살표로 표시한다.
- `@eta`: 도착 예정 시간 패널.
- `@floating-vehicle-status`: 속도, 위치, 위치 정확도, 주행 모드를 지도 위 하단에 간결한 플로팅 카드로 표시한다.
- `@footer`: 하단 고정 제어. `일시 중지`, `주행 종료`; 잠금 상태에서는 같은 위치에서 비활성/잠금 처리.
- `@flow-rail`: 상태 프레임 묶음 옆에 둔다. 실제 앱 UI처럼 보이지 않게 skeleton 검증용 레일로 구성한다.
- `SCR-311` 도착/종료 알트는 별도 전체 화면이 아니라 이 자율주행 화면 위에 플로팅되는 후속 알트로 연결한다.

## Controls And Feedback

- 기본 제어: `일시 중지`, `주행 종료`.
- 안전정차대기: 제어 버튼 위치는 유지하되 비활성/잠금 상태와 이유 문구를 함께 표시한다. 일시정지 요청 후 완전 정차 전까지 화면이 프리즈된 상태임을 표현한다.
- 일시정지 완료: 프리즈가 풀리고 기존 `일시 중지` 버튼 위치가 `운행 재시작`으로 바뀐다.
- 운행 재시작: `운행 재시작` 선택 시 `기존 경로 재시작 하겠습니까?` 확인/취소 알트를 플로팅으로 표시한다. 확인은 기존 경로로 자율주행 재개, 취소는 알트 닫힘으로 flow rail에 표시한다.
- 주행 종료: `주행 종료` 선택 시 안전정차대기 전 확인 모달을 표시한다.
- 차량 상태: 속도, 현재 위치, 주행 모드가 지도 위 플로팅 카드에서 항상 읽힌다. 방향 각도 텍스트는 상태 패널에 두지 않고 지도 안 삼각형 화살표로 표현한다.
- 주행 모드 상태값: `자율주행중`, `수동주행중`, `센터 원격제어중`, `원격재배치중`을 상태 프레임으로 모두 표현한다.
- 경로 상태: 정상 경로, 경로 이탈, 경로 갱신중, 갱신 반영 상태를 지도와 상태 영역에 모두 반영한다.
- 수동 전환 상태에서 `주행 종료`, `자율주행 재요청`은 플로팅 알림 안의 액션으로 둔다.
- 비정차 상태에서 제한 액션을 선택한 경우 `수동주행중 전환` 플로팅 알림은 유지한 채 그 위/근처에 `정차시에만 상태변경이 가능합니다` 토스트를 추가로 표시한다.

## State Variants

- `driving-default`: 자율주행중, 지도 + ETA + 차량 상태 + 제어 가능.
- `safe-stop-waiting`: 일시정지/종료 요청 후 안전정차대기, 완전 정차 전 화면 프리즈, 하단 제어 잠금.
- `paused-ready-to-restart`: 일시정지 요청 후 정차 완료, 프리즈 해제, `일시 중지` 버튼이 `운행 재시작`으로 변경된 상태.
- `restart-confirm-alert`: `운행 재시작` 선택 후 `기존 경로 재시작 하겠습니까?` 확인/취소 알트가 뜬 상태.
- `end-confirm-modal`: `주행 종료` 선택 후 종료 확인 모달이 뜬 상태.
- `manual-override`: 수동주행중 전환. 플로팅 알림에 주행 종료/자율주행 재요청 액션.
- `manual-override-not-stopped`: 수동주행중 전환 알림이 유지된 상태에서 비정차 제한 토스트를 추가 표시.
- `remote-request`: 센터 원격 주행 요청 수신, 승인/거절 플로팅 알림.
- `remote-control`: 원격 요청 승인 후 주행 모드가 센터 원격제어중으로 변경.
- `remote-relocation`: 원격재배치 진입 플래그가 있는 주행 모드.
- `emergency-route-alert`: 긴급 경로 진입 예정 플로팅 알림.
- `route-deviation`: 경로 이탈 상태.
- `route-updating`: 경로 갱신중 상태.
- `route-updated`: 갱신 경로 반영 완료 상태.

## Floating Layers

- `@floating-emergency-alert`: 긴급 경로 진입 예정 알림. 지도 또는 상태 패널 위에 떠야 하며 하단 제어를 가리지 않는다.
- `@floating-restart-confirm-alert`: 기존 경로 재시작 확인/취소 알트. 본문 요소가 아니라 화면 위 플로팅으로 표시한다.
- `@floating-end-confirm-modal`: 주행 종료 확인 모달. 안전정차대기 진입 전 화면 위 플로팅으로 표시한다.
- `@floating-manual-override-alert`: 수동주행중 전환 알림. `manual-override`, `manual-override-not-stopped` 모두 같은 alert 버전/명명으로 통일하고 지도 상단에 배치한다.
- `@floating-remote-request-alert`: 센터 원격 요청 승인/거절 알림. 하단 제어와 독립된 플로팅 카드로 표현한다.
- `@floating-toast`: 정차 필요 토스트. 하단 제어를 가리지 않게 지도 하단 또는 content 하단 위에 뜬다.
- 플로팅 레이어는 상태 프레임 안에 포함하되, `@content`의 고정 카드처럼 배치하지 않는다.
- 사용자에게 보이는 문구만 넣고, 화면 ID, TBD, 내부 데이터명, 구현 설명은 표시하지 않는다.

## Skeleton UX Checks

- 여러 상태 프레임이 `SCR-309.autonomous-driving-progress-skeleton-set` 안에 묶여 같은 화면의 상태임을 알 수 있다.
- 자율주행중/수동주행중/센터 원격제어중/원격재배치중 상태가 모두 표현된다.
- 경로 이탈/갱신중/갱신 반영 상태가 모두 표현된다.
- 팝업, 알림, 토스트가 본문 요소처럼 보이지 않고 플로팅 레이어로 보인다.
- 안전정차대기에서 버튼 잠금 이유가 버튼 비활성만으로 오해되지 않는다.
- 수동 전환 알림은 다른 알림보다 우선순위가 높게 보인다.
- flow rail에서 정상 주행부터 종료까지의 흐름을 확인할 수 있다.
- 사용자 UI에는 화면 ID, 내부 변수명, TBD, 구현 설명을 표시하지 않는다.
