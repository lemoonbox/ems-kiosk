# SCR-312 최적이송병원 — Skeleton Prompt

## Context

- 화면 크기: Mobile app `393 x 852`.
- 진입: `SCR-601 구급활동 일지`에서 이송 병원 추천 선택.
- 이탈: 병원 카드의 이송 요청 진행 상태가 카드 내부에서 승인될 때 이송 방식 선택 팝업을 띄우고, 확정 후 후속 이송 흐름으로 이동한다.
- 화면 유형: 추천 병원 목록과 환자 요약을 함께 보여주는 목록/비교 화면.

## Skeleton Objective

추천 병원 목록에서 여러 병원에 동시에 이동 요청할 수 있고, 각 병원 카드 안에서 승인 대기중/승인/재요청 상태가 진행되는지 검증한다. 병원 이송 방식 선택은 카드 내부 요소가 아니라 화면 위에 뜨는 플로팅 팝업으로 표현한다.

## Structural Layout

- 최상위 섹션: `SCR-312.hospital-recommendation-skeleton-set`.
- 섹션 안에 상태별 프레임을 둔다: `recommendation-ready`, `multi-request-pending`, `partial-approved`, `retry-needed`, `transfer-method-modal`, `loading`, `empty`.
- `@header`: `추천병원 목록` 제목과 뒤로가기 위치.
- `@content`: 상단 환자 정보 summary block, 하단 추천 병원 list.
- 환자 정보 summary: 나이, 성별, 환자 등급 `Class 5`를 한 줄 또는 compact block으로 배치한다.
- 병원 목록: 동일 구조의 병원 카드 3개. 각 카드에는 병원명, 거리, 보조 정보 영역, 카드 내부 요청 상태 영역, `이송 요청`/`대기 : N초`/`이송 시작`/`재요청` 액션 또는 상태 텍스트를 둔다.
- `@footer`: 별도 고정 footer 없음. 병원 카드 안의 CTA로 처리한다.

## Controls And Feedback

- 각 병원 카드의 1차 액션은 초기에는 `이송 요청`이다.
- 여러 병원에 동시에 요청할 수 있으므로 한 카드가 승인 대기중이어도 다른 카드의 이송 요청 버튼은 유지된다.
- 승인 대기중 상태는 병원 추천 박스 내부에 테두리 없는 `대기 : N초` 텍스트로 표시한다. 별도 `대기중` 버튼/칩과 중복 표기하지 않는다.
- 승인된 병원은 별도 `승인` 버튼을 두지 않고, 주요 액션을 `이송 시작`으로 표시한다.
- 병원 이송 방식 선택은 승인된 병원을 선택한 뒤 `@floating-transfer-method-modal`로 화면 위에 뜬다.
- 카드 간 CTA 위치를 동일하게 맞춰 비교와 선택이 쉬워야 한다.
- AI 추천 산정 기준은 앱 내부 정책처럼 보이지 않게 사용자-facing 보조 문구로만 처리한다. `외부 API`, 내부 정책 설명, 구현 설명은 화면에 표시하지 않는다.
- 병원 거절/재요청은 병원 카드 내부 상태로 표현한다. 화면 전체 토스트로 처리하지 않는다.

## State Variants

- `recommendation-ready`: 환자 정보와 추천 병원 목록 표시. 모든 카드가 요청 전 상태.
- `multi-request-pending`: 여러 병원 카드가 동시에 승인 대기중인 상태.
- `partial-approved`: 일부 병원 승인, 다른 병원은 승인 대기중 또는 추가 요청 가능한 상태.
- `retry-needed`: 특정 병원 카드가 재요청 필요 상태로 표시된 상태. 분홍색 재요청 배너/칩은 사용하지 않고 재요청 버튼만 유지한다.
- `transfer-method-modal`: 승인된 병원 선택 후 병원 이송 방식 선택 팝업이 떠 있는 상태.
- `loading`: 추천 API 응답 전 목록 skeleton row 3개.
- `empty`: 추천 병원 없음. 후속 CTA는 임의 확정하지 않되 `TBD`를 화면에 표시하지 않는다.

## Floating Layers

- `@floating-transfer-method-modal`: 병원 이송 방식 선택 팝업. 병원 카드 위에 떠야 하며 본문 카드의 일부처럼 보이면 안 된다.
- 모달 안에는 승인된 병원명, `일반 자율주행`, `응급자율주행`, `일반주행` 선택지, 확인/취소 액션을 둔다.

## Skeleton UX Checks

- 환자 요약이 추천 병원 목록의 기준 정보로 읽힌다.
- 병원명, 거리, 이송 요청 버튼의 위치가 카드마다 일관된다.
- 여러 병원에 동시에 요청할 수 있음을 카드별 상태로 확인할 수 있다.
- 승인 대기 상태가 테두리 없이 `대기 : N초`로 표시되고, 승인 병원은 `이송 시작` 액션으로 이어진다.
- 병원 이송 방식 선택이 플로팅 팝업으로 보이며 카드 본문에 섞이지 않는다.
- 목록이 3개 이상이어도 카드 CTA가 화면 하단에서 잘리지 않는다.
