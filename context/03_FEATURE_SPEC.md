## 2. V1.1 Feature Details

### FEAT-303. 주행 옵션 설정

| 항목 | 내용 |
| --- | --- |
| 목적 | 주행 방식과 출동 유형을 설정하고, 필요 시 원격 주행 신청을 시작한다. |
| 사용자 | EMS 키오스크 사용자 |
| 관련 화면 | SCR-305 |
| 관련 정책 | POL-303, POL-401, POL-404 |
| 관련 데이터 | DATA-311, DATA-401 |
| 상태 | Draft |

#### Main Behavior

1. 사용자는 주행 방식과 출동 유형을 선택한다.
2. 주행 방식 `수동주행/자율주행`과 출동 유형 `일상 업무/응급 출동`은 모두 필수 선택이며 기본값은 없다.
3. V1.1에서는 운행 앰뷸런스가 1대이므로 차량 선택 필드를 제공하지 않는다.
4. 차량상태 조회는 사용자 선택 절차가 아니라 시스템 상태 확인으로 처리한다.
5. 사용자는 SCR-305 안의 주행 옵션으로 EMS->센터 원격 주행 신청을 선택할 수 있다.
6. EMS->센터 원격 주행 신청 후 센터 승인 전까지 승인대기 상태를 표시한다.
7. 센터 승인 시 자율주행 진행 화면을 유지하거나 진입한다.
8. 센터 거절 또는 타임아웃 시 주행 옵션 또는 기존 진행 화면으로 복귀한다.

### FEAT-304. 앰뷸런스 차량상태 조회

| 항목 | 내용 |
| --- | --- |
| 목적 | 단일 운행 앰뷸런스의 운행 가능 상태를 확인한다. |
| 사용자 | EMS 키오스크 사용자, 센터시스템 |
| 관련 화면 | SCR-305 또는 SCR-309 |
| 관련 정책 | POL-402 |
| 관련 데이터 | DATA-402, DATA-403 |
| 상태 | Draft |

#### Main Behavior

1. EMS 키오스크는 차량상태 조회를 요청한다.
2. 차량 시동이 걸리지 않은 상태 등으로 응답이 없으면 10초 후 타임아웃 처리한다.
3. 차량상태는 `대기`, `주행중`, `비정상` 중 하나로 송신된다.
4. 상태별 판정 기준은 협의 필요로 관리한다.
5. 미응답 10초 타임아웃 안내는 SCR-305에 표시한다.

### FEAT-305. 경로 확인 및 표시 전환

| 항목 | 내용 |
| --- | --- |
| 목적 | 생성된 경로를 확인하고 필요 시 재요청 또는 주행시작을 수행한다. |
| 사용자 | EMS 키오스크 사용자 |
| 관련 화면 | SCR-307, SCR-308 |
| 관련 정책 | POL-305, POL-403 |
| 관련 데이터 | DATA-404, DATA-405 |
| 상태 | Draft |

#### Main Behavior

1. 일반 자율주행 경로 생성은 기존 정책을 유지한다.
2. 응급 자율주행 경로 생성 시 센터시스템은 일반 경로와 응급 경로를 모두 제공한다.
3. EMS 키오스크는 두 경로를 모두 EMS에 표기할 수 있어야 한다.
4. 카카오맵 위 단추 메뉴는 경로 표시만 전환한다.
5. 경로 표시 전환은 경로 재생성 요청이 아니다.
6. 일반/응급 경로 표시 전환 후에도 사용자는 같은 경로확인 화면에서 주행시작을 실행할 수 있다.
7. 재요청은 주행 옵션 단계로 돌아가지 않고 경로만 다시 생성한다.

### FEAT-306. 주행 시작 및 진행 제어

| 항목 | 내용 |
| --- | --- |
| 목적 | 주행 시작 후 사용자가 가능한 제어를 수행하고, 제어 불가 상태를 명확히 인지하게 한다. |
| 사용자 | EMS 키오스크 사용자 |
| 관련 화면 | SCR-309, SCR-310 |
| 관련 정책 | POL-306, POL-405 |
| 관련 데이터 | DATA-406, DATA-407 |
| 상태 | Draft |

#### Main Behavior

1. 자율주행 시작 시 SCR-309 자율주행 진행 화면으로 진입한다.
2. 수동주행 시작 시 SCR-310 수동주행 진행 화면으로 진입한다.
3. 자율주행 중 일시정지 또는 주행 종료는 즉시 완료되지 않고 안전정차대기 상태로 전환된다.
4. 일시정지 선택 시 차량이 정차모드로 바뀌고 완전 정차 전까지 화면을 프리즈한다.
5. 정차가 완료되면 화면 프리즈를 해제하고 `일시정지` 버튼을 `운행 재시작`으로 변경한다.
6. `운행 재시작` 선택 시 `기존 경로 재시작 하겠습니까?` 확인/취소 알트를 표시한다. 확인 시 기존 경로로 자율주행을 재개하고, 취소 시 알트만 닫는다.
7. 주행 종료 실행 전에는 확인 모달을 표시한다.
8. 주행 종료 확인 후 안전한 자리에 정차하기 전까지 컨트롤 패널을 잠근다.
9. 안전 정차 완료 수신 후 요청한 일시정지 또는 종료 후속 처리를 수행한다.
10. 자율주행 시스템에 의한 자동 종료 시퀀스는 협의 필요로 관리한다.

### FEAT-312. 실시간 차량 상태 표기

| 항목 | 내용 |
| --- | --- |
| 목적 | 자율주행 중 차량의 현재 상태를 EMS 키오스크 사용자가 실시간으로 확인한다. |
| 사용자 | EMS 키오스크 사용자 |
| 관련 화면 | SCR-309 |
| 관련 정책 | POL-406 |
| 관련 데이터 | DATA-408~DATA-411 |
| 상태 | 협의 필요 |

#### Main Behavior

1. 자율주행 진행 중 차량속도를 표시한다.
2. 자율주행 진행 중 차량위치를 표시한다.
3. 자율주행 진행 중 차량방향(heading)을 표시한다.
4. 자율주행 진행 중 자율주행모드를 표시한다.
5. 차량 상태 정보 수신 주기는 100ms가 아닌 500ms 간격 적용 가능 여부를 협의한다.

### FEAT-313. 원격 자율주행 요청

| 항목 | 내용 |
| --- | --- |
| 목적 | EMS와 센터 간 원격 자율주행 요청을 승인/거절/대기/타임아웃 상태로 처리한다. |
| 사용자 | EMS 키오스크 사용자, 센터 관제자 |
| 관련 화면 | SCR-305, SCR-309 |
| 관련 정책 | POL-407 |
| 관련 데이터 | DATA-413~DATA-416 |
| 상태 | Draft |

#### Main Behavior

1. EMS 사용자는 SCR-305에서 원격 주행 신청을 시작할 수 있다.
2. EMS->센터 요청은 센터 승인까지 승인대기 상태로 표시한다.
3. 센터 승인 시 자율주행 진행 화면을 유지하거나 진입한다.
4. 센터 거절 시 거절 안내 후 주행 옵션 또는 기존 상태로 복귀한다.
5. 센터->EMS 요청은 화면 위치와 무관한 글로벌 승인/거절 알림으로 표시한다.
6. EMS 사용자가 승인하면 승인 결과를 센터에 송신하고 자율주행 진행 화면을 유지한다.
7. EMS 사용자가 거절하면 거절 결과를 센터에 송신하고 기존 상태를 유지한다.
8. 양방향 타임아웃 시간과 타임아웃 시 기본 처리는 협의 필요다.

### FEAT-315. 자율주행 중 수동 전환

| 항목 | 내용 |
| --- | --- |
| 목적 | 운전자 조작에 의해 자율주행이 수동주행으로 전환된 사실과 후속 조치를 EMS 키오스크에 명확히 표시한다. |
| 사용자 | EMS 키오스크 사용자, 앰뷸런스 운전자 |
| 관련 화면 | SCR-309 |
| 관련 정책 | POL-409 |
| 관련 데이터 | DATA-418 |
| 상태 | Draft |

#### Main Behavior

1. 자율주행 중 운전자가 운전대 또는 페달을 조작하면 즉시 수동 모드로 전환된다.
2. 센터시스템은 수동모드 변경 알람을 EMS 키오스크에 제공한다.
3. EMS 키오스크는 SCR-309에 수동 주행중 알림을 표시한다.
4. 알림에는 주행 종료와 자율주행 재요청 버튼이 있다.
5. 주행 종료와 자율주행 재요청은 정차시에만 실행 가능하다.
6. 정차중이 아니면 `정차시에만 상태 변경이 가능합니다` 토스트를 표시한다.
7. 주행 종료 시 현행 수동주행과 자율주행을 모두 종료하고 이벤트를 종료한다.
8. 자율주행 재요청 시 이벤트는 유지하고 자율주행 코스를 재산정한다.
9. SCR-310은 원래 수동주행 화면이므로 별도 수동 전환 알림 대상이 아니다.

#### Main Behavior

### FEAT-318. 원격재배치 상태 표기

| 항목 | 내용 |
| --- | --- |
| 목적 | 원격재배치 버튼으로 시작한 목적지 선택 이후 주행 상태를 원격재배치중으로 구분한다. |
| 사용자 | EMS 키오스크 사용자, 센터 관제자 |

3. 원격재배치 버튼을 통해 경로 검색에 진입할 수 있다.
4. 원격재배치 버튼으로 진입한 경우에도 목적지 선택 자체는 일반 주소/즐겨찾기 선택과 동일하게 처리한다.
5. 목적지 선택 후 후속 주행 상태를 원격재배치중으로 표기한다.
