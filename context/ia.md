# IA & Service Flow — EMS Kiosk V1.1

이 문서는 Codex Figma UI design workflow가 기대하는 IA 기준 파일이다. 상세 역기획 원본은 `02_IA.md`, 기능/상태 상세는 `03_FEATURE_SPEC.md`와 `10_STATE_POLICY.md`를 따른다.

## IA 구조

```text
Global
  SCR-301 메인화면
    -> SCR-302 주소검색
      -> SCR-303 주소검색 결과
      -> SCR-304 목적지 확인
    -> SCR-305 주행 옵션 설정

FLOW-003 자율주행 생성 및 컨트롤
  SCR-304 목적지 확인
    -> SCR-305 주행 옵션 설정
      -> EMS->센터 원격 주행 승인대기
      -> SCR-307 경로확인
      -> SCR-308 경로확인
    -> SCR-309 자율주행 진행
      -> SCR-311 목적지 도착 알트
    -> SCR-310 수동주행 진행
      -> 완료

주행 중 이벤트
  센터 원격주행 요청 -> SCR-309 알림
  긴급 경로 진입 예정 -> SCR-309 알림
  운전대/페달 조작 -> SCR-309 수동 전환 알림
  경로 이탈/갱신 -> SCR-309 상태 영역

FLOW-006 구급활동 일지 및 병원 이송
  SCR-311 목적지 도착
    -> SCR-601 구급활동 일지
      -> SCR-312 최적이송병원
        -> SCR-313 이송 요청 대기
          -> SCR-314 병원 이송 주행 방식 선택
            -> SCR-305 주행 옵션 설정

Deprecated
  SCR-306 운행 차량 선택
```

## 네비게이션 패턴

| 패턴 | 적용 화면 | 설명 |
|---|---|---|
| Stack flow | SCR-301~SCR-305 | 목적지 검색부터 주행 옵션까지 선형으로 이동한다. |
| Stateful driving surface | SCR-309, SCR-310 | 주행 중 이벤트와 제어 가능 상태가 같은 화면에서 바뀐다. |
| Event alert layer | SCR-309 | 센터 원격 요청, 긴급 경로, 수동 전환 알림을 주행 화면 위에 표시한다. |
| Loop | SCR-314 -> SCR-305 | 병원 승인 후 선택한 병원을 새 목적지로 주행 생성 루프에 재진입한다. |
| Deprecated screen | SCR-306 | 차량 1대 정책으로 사용하지 않는다. |
| Modal | SCR-602 | 구급일지 종료 확인 등 확인성 액션에 사용한다. |

## 엣지 케이스

### 목적지/검색

- 최근 검색은 최대 5개 표시, 최신순 정렬, 1개월 보관, 1개월 경과 또는 5개 초과 시 자동 삭제한다.
- 즐겨찾기 등록/수정은 별도 즐겨찾기 관리 화면에서 처리한다.
- 원격재배치 버튼으로 진입해도 즐겨찾기는 목적지 유형이 아니라 선택 수단이다.

### 차량/옵션

- SCR-306 차량 선택 화면은 V1.1에서 진입하지 않는다.
- 차량은 1대뿐이며, 사용자는 차량을 선택하지 않는다.
- 차량상태 대기/주행중/비정상 판정 기준은 회의 논의 필요 항목이다.
- 차량상태 미응답 10초 타임아웃 안내는 SCR-305에 표시한다.

### 원격주행/알림

- 원격주행 타임아웃 시간과 기본 처리는 회의 논의 필요 항목이다.
- 센터->EMS 원격주행 요청 알림은 화면 위치와 무관한 글로벌 알림으로 표시한다.
- 긴급 경로 진입 알림 선행 시간은 회의 논의 필요 항목이다.

### 주행 제어

- 자율주행 일시정지 시 정차모드로 전환하고 완전 정차 전까지 화면을 프리즈한다. 정차 후 프리즈가 풀리면 `일시정지` 버튼은 `운행 재시작`으로 바뀐다.
- `운행 재시작` 선택 시 `기존 경로 재시작 하겠습니까?` 확인/취소 알트가 뜨며, 확인 시 기존 경로로 자율주행을 재개하고 취소 시 알트만 닫는다.
- 주행 종료 전 확인 모달이 필요하다.
- 안전 정차 전에는 일시정지/종료/재요청 등 위험한 제어를 잠근다.
- 수동 전환 후 주행 종료/자율주행 재요청은 정차 상태에서만 실행한다.

### 병원 이송 루프

- 병원 승인 후 SCR-314에서 선택한 병원을 목적지로 SCR-305에 재진입한다.
- Q-314는 “SCR-305 재진입”으로 문서화했으며 추적성 문서에서 Applied 처리됐다.
