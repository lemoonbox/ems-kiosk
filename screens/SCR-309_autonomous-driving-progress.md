## 2. Screen Purpose

### Observed

- 상단에 목적지 주소가 표시된다.
- 지도 영역과 경로 표시가 유지된다.
- 하단에 `일시 중지`, `주행 종료` 버튼이 표시된다.
- `도착 예정 시간`과 예시값 `13시 23분`이 표시된다.

### V1.1 Updated

- 자율주행 진행 중 차량속도, 차량위치, 차량방향(heading), 자율주행모드를 실시간 표기한다.
- 주행모드는 자율주행중, 수동주행중, 센터 원격제어중, 원격재배치중 등으로 표시한다.
- 긴급 경로 진입 전 EMS에 사전 알림을 표시한다.
- 운전자가 운전대 또는 페달을 조작해 수동 모드로 전환되면 수동주행중 알림을 표시한다.
- 센터에서 원격 주행을 요청하면 EMS에서 승인/거절 가능한 알림을 표시한다.
- 센터->EMS 원격 주행 요청 알림은 화면 위치와 무관한 글로벌 알림으로 표시한다.
- 일시정지 선택 시 차량이 정차모드로 바뀌고 완전 정차 전까지 화면을 프리즈한다.
- 정차가 완료되면 프리즈를 해제하고 `일시 중지` 버튼을 `운행 재시작`으로 변경한다.
- `운행 재시작` 선택 시 `기존 경로 재시작 하겠습니까?` 확인/취소 알트를 표시한다. 확인 시 기존 경로로 자율주행을 재개하고 취소 시 알트만 닫는다.
- 주행 종료 요청 전에는 확인 모달을 표시한다. 확인 후 안전한 정차 지점에 도달하기 전까지 컨트롤 패널을 잠그고 상태를 표시한다.
- 경로 이탈 및 갱신 경로 수신 시 지도와 주행경로 상태를 갱신한다.

### Questions

- DEC-1.1-002: EMS -> 센터 원격 주행 신청 타임아웃은 몇 초인가?
- DEC-1.1-003: 센터 -> EMS 원격 주행 요청 타임아웃 및 기본 처리는 무엇인가?
- DEC-1.1-004: 긴급 경로 진입 알림 선행 시간 NN초는 몇 초인가?
- DEC-1.1-006: 자율주행 시스템에 의한 자동 종료 시퀀스는 무엇인가?
- DEC-1.1-007: 주행 모드 상태값 표준 목록 및 표시 우선순위는 무엇인가?
- DEC-1.1-009: 차량 상태 정보 수신 주기를 100ms가 아니라 500ms로 적용 가능한가?
