## 6. Global State Flow

앰뷸런스/미션/환자/연동 상태처럼 여러 화면에 걸쳐 영향을 주는 상태를 정리한다.

```mermaid
stateDiagram-v2
  [*] --> 목적지선택
  목적지선택 --> 주행옵션설정
  주행옵션설정 --> 경로확인
  경로확인 --> 자율주행중
  경로확인 --> 수동주행중
  자율주행중 --> 안전정차대기: 일시정지/종료
  안전정차대기 --> 일시정지완료: 일시정지 정차 완료
  일시정지완료 --> 자율주행중: 운행 재시작 확인
  안전정차대기 --> 목적지도착: 안전정차 후 종료
  자율주행중 --> 수동주행중: 운전대/페달 조작
  자율주행중 --> 원격제어중: 센터 원격제어
  자율주행중 --> 원격재배치중: 원격재배치
  자율주행중 --> 경로갱신중: 경로 이탈
  경로갱신중 --> 자율주행중: 갱신 경로 반영
  목적지도착 --> [*]
```
