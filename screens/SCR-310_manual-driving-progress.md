## 2. Screen Purpose

### Observed

- 상단에 목적지 주소가 표시된다.
- 하단에 `주행 종료` 버튼만 표시된다.
- 수동주행 화면은 자율주행 화면과 달리 `일시 중지` 버튼이 없다.

### Inferred

- 수동주행 중에는 앱이 경로 제어나 일시정지를 제공하지 않고 종료 처리만 제공한다.
- 수동주행 종료 후에는 SCR-311 도착/종료 알트를 띄우지 않고 직접 완료 처리한다.
- 주행 종료 실행 전에는 확인 모달을 표시한다.

### Questions

- 없음. 주행 종료 확인 모달과 수동주행 확인 CTA 정책은 사용자 확인 완료.
