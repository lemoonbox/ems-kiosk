## 2. Background

### Observed

- 피그마 기준 EMS 키오스크는 목적지 검색, 주행 옵션 설정, 차량 선택, 경로 확인, 자율주행 진행, 수동주행 진행, 목적지 도착, 최적이송병원 추천 플로우를 포함한다.
- 기존 자율주행 진행 화면은 일시 중지와 주행 종료 제어를 제공한다.
- 기존 수동주행 진행 화면은 주행 종료 제어를 제공한다.

### Inferred

- EMS 키오스크는 센터시스템, ADS, 지도 API와 연동되는 주행 제어 UI 역할을 가진다.
- V1.1에서는 단순 경로 생성/주행 시작보다 주행 중 상태 변화, 원격 요청, 경로 갱신, 안전 정차 대기 상태가 더 중요해진다.
- 차량 선택 화면은 운행 앰뷸런스가 1대로 변경되면서 제거 또는 우회되어야 한다.
- 스케줄 시작은 저장된 목적지를 사용해 주행 옵션 설정으로 바로 이동한다.
- 수동주행은 실제 경로 생성이 아니므로 수동주행 확인 단계의 CTA는 `확인`으로 표시한다.

### Questions

- 원격주행 요청 타임아웃 시간은 협의 필요하다.
- 긴급 경로 진입 알람 선행 시간은 협의 필요하다.
- 차량상태 `대기 / 주행중 / 비정상` 판정 기준은 협의 필요하다.
- 차량 상태 정보 수신 주기를 100ms가 아닌 500ms 간격으로 적용 가능한지 협의 필요하다.
- 자율주행 시스템에 의한 자동 종료 시퀀스는 협의 필요하다.
- 주행 모드 상태값 표준 목록과 표시 우선순위는 협의 필요하다.
